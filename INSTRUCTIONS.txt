=======================================================
ILO PNEUMOCONIOSIS CLASSIFIER SUITE
Distribution Package & Installation Guide
=======================================================

This software can be distributed in three different ways, depending on who needs to use it:

1. VIEWER DISTRIBUTION (Viewer_Distribution folder)
   Send this folder to the Interpreter/Physician. It only contains the Viewer App.
   - Windows: Double-click `start_viewer_windows.bat`
   - Mac/Linux: Run `./start_viewer_mac_linux.sh`
   It automatically installs dependencies and opens the Viewer in the browser at http://localhost:3000.

2. PUSHER DISTRIBUTION (Pusher_Distribution folder)
   Send this folder to the X-Ray Technician. It only contains the Pusher App.
   - Windows: Double-click `start_pusher_windows.bat`
   - Mac/Linux: Run `./start_pusher_mac_linux.sh`
   It automatically installs dependencies and opens the Pusher in the browser at http://localhost:3002.

3. UNIFIED DISTRIBUTION (Unified_Distribution folder or the root ILO_RAD folder)
   Use this if you want both apps on the same computer, or if you want to distribute a single ZIP file where the user can choose their role.
   - Windows: Double-click `start_windows.bat`
   - Mac/Linux: Run `./start_mac_linux.sh`
   When run, an interactive menu will appear in the terminal prompting you to select your role (Viewer or Pusher). It will then automatically start the correct application and open the browser.

-------------------------------------------------------
HOW TO USE
-------------------------------------------------------
- Ensure you have Node.js installed before running any of the `.bat` or `.sh` files. If you don't have it, download it from https://nodejs.org/.
- Keep the black terminal window open while you are using the app. When you're done, simply close the terminal window to stop the servers.
- The applications run completely locally and securely on your own network.

-------------------------------------------------------
NETWORK SETUP GUIDE (PACS & Push Connections)
-------------------------------------------------------
This suite allows you to connect directly to an existing PACS server (like Orthanc) using the DICOMweb standard, OR you can use the included Pusher App for a direct push workflow.

OPTION A: CONNECTING TO A PACS SERVER (Orthanc / DICOMweb)
1. Ensure your PACS (e.g., Orthanc) has the DICOMweb plugin installed and enabled.
2. The PACS server must have CORS (Cross-Origin Resource Sharing) configured to allow the Viewer App to make requests.
   - For Orthanc, set `"CorsAllowedOrigins": ["*"]` in the configuration file.
3. Open the Viewer App and click on the "Connect to PACS" button.
4. Go to the "Network Setup & Instructions" tab.
5. Enter your PACS DICOMweb URL (e.g., `http://192.168.1.100:8042/dicom-web`).
6. Enter the Username and Password if your PACS server requires authentication.
7. Go to the "Query / Retrieve" tab, enter the patient details, and click "Search" to query and load images using QIDO-RS and WADO-RS.

OPTION B: DIRECT PUSH WORKFLOW (Pusher App)
1. THE RECEIVER (Viewer App)
   - Role: The Interpreter/Physician's computer.
   - IP Address: Find the Local IP of this computer.
     * Windows: Use 'ipconfig' in Command Prompt (look for IPv4 Address).
     * Mac: Use 'ifconfig | grep inet' in Terminal or check System Settings.
     * Linux: Use 'ip a' or 'hostname -I' in Terminal.
     Example: 192.168.1.100
   - Port Number: 3000
2. THE PUSHER (Pusher App)
   - Role: The X-Ray Technician's computer.
   - Open the PUSHER APP on the technician's computer.
   - In the "Target Interpreter URL" box, enter the receiver's address:
     http://192.168.1.100:3000/api/dicom-receiver
   - Drag and drop your DICOM file. It will push directly to the Viewer!

## Privacy & Data Confidentiality
* **100% Local & Offline**: This software suite is designed to run entirely locally on your own hardware or local area network.
* **No Telemetry & No Cloud Storage**: We do not collect usage data, analytics, or store your patient data in any external cloud server. 
* **Data Security**: DICOM files transferred via the Pusher App or loaded directly do not leave your network. It is the user's responsibility to ensure the host machine complies with local medical data regulations (e.g., HIPAA, GDPR).

## Why This Suite is Novel
* **Zero Server Configuration**: Unlike traditional PACS solutions, you can immediately push DICOM files directly from the acquisition PC to the doctor's screen via a simple drag-and-drop interface over the local network (or VPNs like Tailscale).
* **Modern Side-by-Side Viewing**: Combines an integrated medical DICOM viewer seamlessly with the standard ILO 2022 Reference Radiographs (digitized in high-resolution DICOM and JPEG formats) directly in your browser.
* **Instant Digital Reporting**: Replaces paper ILO forms with an interactive, validating digital wizard that generates standardized PDFs locally.



## Updates and Versioning
**Current Version:** 1.0.0

To check if a newer version of the software is available, visit the [GitHub Repository](https://github.com/arka1985/ILO_RAD) (you can also click the "Updates" button in the Viewer App footer).

**How to Install an Update:**
1. Download the new `.zip` package from GitHub and extract it to a **new folder**.
2. **Do not overwrite** the old folder immediately. The software runs locally and your browser saves your settings based on the local address. 
3. If you want to keep your patient history, your browser's `localStorage` will automatically carry over as long as you open the new version in the same browser on the same computer (e.g., `localhost:3000`).
4. Once you have verified the new version works and your history is intact, you can safely delete the old folder.
