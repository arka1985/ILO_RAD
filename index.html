Important Setup Instructions:

  1. After downloading, cut or copy the downloaded .zip file from your Downloads folder.
  2. Paste it into your C: drive (or any separate safe storage space depending on your OS). Why? It is highly undesirable to unzip directly into the Downloads folder because that folder is frequently cleared out. If the software is accidentally deleted, you will lose your local patient data and have to redownload the large package.
  3. Once pasted in the safe location, unzip it (e.g., Right-click the file and select "Extract All").
  4. After extraction, you can safely delete the original .zip file so it doesn't block your storage space.
  5. Windows Smart App Control: If you find that Windows Smart App Control is blocking the app from running, you can safely turn it off. Go to Windows Security > App & browser control > Smart App Control settings, and select Off. (Note: This is required because the app is a locally running server and is not a digitally signed Microsoft Store app).
  6. Light & Dark Theme: The application supports both Dark (default) and Light viewing modes. You can instantly toggle between them at any time by clicking the Sun/Moon icon located on the far right side of the main header.

Desktop Shortcut: Inside the downloaded folder, you can double-click Create_Desktop_Shortcut.vbs to create an easy launch shortcut on your Desktop.

What is ILO Radiography?

The International Labour Organization (ILO) International Classification of Radiographs of Pneumoconioses is the globally accepted standard system for evaluating chest radiographs (PA view X-rays). It provides a systematic, simple, and reproducible framework to detect and classify occupational dust-induced lung diseases—collectively known as pneumoconioses (such as silicosis, coal worker's pneumoconiosis, and asbestosis).

Its primary purpose is to establish a standardized, uniform method to record the presence, type, and severity of parenchymal and pleural lung abnormalities. This meticulous grading is crucial for epidemiological research, workplace health screening, and the ongoing medical surveillance of workers exposed to hazardous respirable dusts.

Statutory Requirements in India: Under the Occupational Safety, Health and Working Conditions (Central) Rules, periodic medical surveillance of workers engaged in hazardous mining or industrial operations is legally mandatory. The classification of these chest radiographs must adhere strictly to the ILO standard, and the findings must be officially recorded and reported using prescribed statutory formats (such as Form IX). Proper ILO grading is a vital legal requirement for determining worker fitness, evaluating occupational disease compensation claims, and maintaining permanent health registries.

This software suite modernizes the evaluation process by providing an interactive, digital side-by-side viewer of the standard ILO 2022 reference images alongside the patient's DICOM files, while simultaneously auto-generating the legally required physical reports (including the mandatory Form IX) for instant printing and archiving.

Hardware & Configuration Requirements

Computer Requirements

  • Operating System: Windows 10/11, macOS, or Linux.
  • Processor: Modern multi-core processor (Intel Core i5 / AMD Ryzen 5 / Apple M1 or better recommended).
  • Memory (RAM): Minimum 8 GB (16 GB or higher recommended).
  • Storage: At least 2 GB of free disk space.
  • Web Browser: Latest version of Google Chrome or Mozilla Firefox.
  • Internet Connection: Only required for PACS features. Otherwise, fully offline.

Diagnostic Monitor (As per ILO)

  • Type: Flat Panel display terminal.
  • Resolution: Minimum 3 Megapixels (e.g., 2048 × 1536).
  • Luminance: Maximum luminance of at least 250 cd/m².
  • Contrast Ratio: Minimum contrast ratio of 250:1.
  • Calibration: DICOM Part 14 Grayscale Standard Display Function (GSDF).
  • Display Size: Minimum 21 inches diagonal.

How to Run

Prerequisites

  • Node.js: Required to run this application. Download the LTS version.
  • Other Dependencies: Automatically installed on first run.

Browser Note: We highly recommend using Google Chrome or Mozilla Firefox.

Windows

  1. Double-click the .bat file (e.g., start_windows.bat).
  2. The script installs dependencies, boots the server, and opens your browser.
  3. Unified Distribution: Press 1 for Viewer or 2 for Pusher.

Mac / Linux

  1. Open a terminal and run chmod +x start_mac_linux.sh.
  2. Run ./start_mac_linux.sh.
  3. Unified Distribution: Press 1 for Viewer or 2 for Pusher.

How to Use the Viewer App

  1. Be comfortably seated in front of the diagnostic display monitor, 25 cm away.
  2. Launch the Viewer (Opens at http://localhost:3000).
  3. Fill out the Reporting Wizard on the left side of the screen.
  4. Click "POP OUT DUAL VIEWER PANEL" to open the side-by-side image viewer in a new window.
    Note: For optimal workflow, the dual viewer panel should be extended to your secondary diagnostic screen. If using a laptop, connect your secondary monitor directly. If using a desktop, use an HDMI splitter (or secondary display port).

    How to Extend Your Display: Press Windows Key + P (or System Preferences → Displays on Mac) and select "Extend". Drag the popped-out window to the medical monitor.
  5. Load a patient DICOM file (via Upload, PACS, or pushed from the Technician).
  6. Compare the patient's X-ray against the ILO Standard Reference Images and fill the form systematically.
  7. Generate and save your final PDF report.

How to Use the Pusher App

  1. Launch the Pusher (Opens at http://localhost:3002).
  2. Find the IP Address of the doctor's computer.
    • Local Network: Use ipconfig (Windows), ifconfig (Mac), or ip a (Linux). Example: 192.168.1.100
    • Remote Network: Use Tailscale to get a secure IP (e.g. 100.115.92.2).
  3. In the Pusher App, enter the target address:
    http://192.168.1.100:3000/api/dicom-receiver
  4. Drag and drop a patient's .dcm file into the designated area, or upload it directly from any local or external storage drive.
  5. The image will instantly appear on the doctor's screen without them needing to refresh!

How to Use PACS

If your facility uses a PACS server (like Orthanc) with a DICOMweb endpoint enabled:

  1. Open the Viewer App and click the "Connect to PACS" button.
  2. In the "Network Setup" tab, enter your PACS DICOMweb URL
    http://192.168.1.50:8042/dicom-web
  3. Provide a Username and Password if required.
  4. Go to the "Query / Retrieve" tab.
  5. Enter the Patient Name or ID and click Search.
  6. Click on any study to instantly fetch and render the DICOM files!
